Booting GeoGenesis

loading the WebAssembly simulation engine…

GeoGenesis needs WebAssembly. If loading stalls, enable WebAssembly (Tor: security level Safer/Standard; Safari: turn off Lockdown Mode) or open the demo in a normal Chrome, Edge, Firefox or Safari window.

Custom geology

Optionally load a custom rock catalogue and/or a strata stack as JSON. They are sent with the next Generate and saved inside project files.

No custom rocks — engine defaults
No custom strata — engine defaults

No custom geology — the engine defaults will be used.

Example files: examples/custom-rocks.json, examples/strata.json.

Reading the simulation

The left panel generates the world; the timeline advances geological time; the right panel measures the result. Drag on the minimap to move the cross-section line. The Run button replays the configured duration and reports progress in the status bar. Use the Export menu to save or load a project, Suggest to preview candidate worlds without touching the current one, and the layers button next to the preset to load custom rocks or strata.

Determinism

Worlds are deterministic: the same parameters and seed reproduce the same terrain. Exported project JSON records the seed, preset and engine version so a result can be regenerated later.
